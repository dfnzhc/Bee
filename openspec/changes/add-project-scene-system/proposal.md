# Proposal

## Why

Bee 目前启动后打开内置场景，Render Flow 的编辑结果只保存在本次运行中。项目和场景文件让用户能在同一项目中维护多套场景与渲染配置，退出后继续工作，也能携带整个项目目录迁移到其他位置。

## What Changes

- **BREAKING** 启动时先选择或新建项目。项目选择页提供最近项目，工作台提供切换和关闭项目的入口。
- 新建项目生成带版本号的 `project.beeproj`、首个场景文件和 `Assets/`。首场景可使用空白或内置示例模板。
- 顶栏提供场景切换、新建、复制、重命名、删除和设置启动场景。场景独立保存内容、起始视角、渲染设置以及 Render Flow 的草稿与生效版本。
- 提供显式保存、离开前的未保存提示和上一份有效备份恢复。项目或场景加载成功后再切换工作台和视口状态。
- `Files` 抽屉打开时默认浏览当前项目的 `Assets/`，并保留显式选择外部目录的只读浏览入口。
- 首版验收覆盖项目目录迁移、Windows 保存中断恢复，以及空白场景在光栅化和路径追踪下的显示。

## Capabilities

### New Capabilities

- `project-scenes`: 本地项目目录、场景文档、项目与场景生命周期，以及保存和恢复。

### Modified Capabilities

- `editor-workbench`: 进入项目后显示工作台，增加项目和保存菜单项、当前项目与场景标识及场景选择器。
- `workspace-files`: 使用当前项目的资源根目录作为默认浏览位置，隔离项目内浏览和显式外部浏览。
- `interactive-viewport`: 显示加载的场景，切换时隔离在途结果，支持无几何体和灯光的空白场景。
- `render-graph`: 按场景恢复草稿与生效配置，在设备不支持配置时提供可用的预览。

## Impact

- `crates/bee` 中的应用入口、工作台、文件抽屉、Render Flow 和视口接入项目会话。
- `crates/scene` 提供空白模板和从持久化场景初始化状态的入口。`crates/renderer` 涉及流程图往返与空场景的两条渲染路径，按实际验证结果补齐 Vulkan 端的空输入处理。
- README 和相关测试更新启动、保存、项目迁移及设备验收流程。
