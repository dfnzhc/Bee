# Spec Delta

## MODIFIED Requirements

### Requirement: 选择要浏览的文件夹
系统 SHALL 将当前项目的 `Assets/` 作为文件窗口的默认根目录，并显示当前浏览位置。系统 SHALL 保留显式选择本地文件夹的只读浏览入口，并提供返回项目资源根目录的方式。

#### Scenario: 首次打开文件窗口
- **WHEN** 用户成功打开项目后首次展开 `Files` 抽屉
- **THEN** 文件窗口显示该项目 `Assets/` 的实际内容或相应的空目录、读取失败状态

#### Scenario: 选择文件夹
- **WHEN** 用户通过 `Browse Folder…` 选择一个可读取的文件夹
- **THEN** 文件窗口显示该文件夹路径及其真实目录内容，并提供返回当前项目 `Assets/` 的入口

#### Scenario: 取消文件夹选择
- **WHEN** 用户取消文件夹选择
- **THEN** 文件窗口保留之前的浏览位置

#### Scenario: 在同一项目中切换场景
- **WHEN** 用户切换到当前项目中的另一个场景
- **THEN** 文件窗口保留该项目当前的浏览位置

#### Scenario: 切换项目
- **WHEN** 用户成功打开另一个项目
- **THEN** 文件窗口将浏览位置重置到新项目的 `Assets/`
- **AND** 旧项目尚未完成的目录读取或选择结果不得更新当前文件列表

### Requirement: 只读浏览目录内容
系统 SHALL 区分展示文件和文件夹，并允许用户进入子文件夹及返回上一级。项目资源浏览 SHALL 以当前项目的资源根目录为边界，浏览操作不得修改文件系统内容。

#### Scenario: 浏览子文件夹
- **WHEN** 用户进入一个可读取的子文件夹
- **THEN** 界面更新当前路径与实际目录内容，并提供返回上一级的方式

#### Scenario: 到达项目资源根目录
- **WHEN** 用户在项目资源模式下到达 `Assets/` 根目录
- **THEN** `Up` 不可用，进入目录联接等路径也不得越出资源根目录
- **AND** 用户仍可通过 `Browse Folder…` 显式选择其他目录

#### Scenario: 目录为空
- **WHEN** 当前文件夹没有可显示的条目
- **THEN** 界面显示空目录状态

#### Scenario: 浏览普通文件
- **WHEN** 当前目录包含普通文件
- **THEN** 界面显示其名称并与文件夹区分
- **AND** 不将尚未实现的导入、场景打开或文件编辑操作显示为可用
