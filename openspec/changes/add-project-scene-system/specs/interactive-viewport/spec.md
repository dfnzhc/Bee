# Spec Delta

## MODIFIED Requirements

### Requirement: 在编辑器中展示场景画面
系统 SHALL 在桌面编辑器的视口中展示由自研渲染器生成的当前项目场景画面。

#### Scenario: 打开编辑器
- **WHEN** 用户创建或打开项目并成功加载其中一个场景，且渲染设备可用
- **THEN** 编辑器根据该场景的内容、起始相机和渲染设置显示画面

## ADDED Requirements

### Requirement: 隔离项目和场景切换的渲染结果
系统 SHALL 在成功切换项目或场景时撤下旧场景画面和累计样本，当前视口 SHALL 只接收与切换后场景相符的渲染结果。

#### Scenario: 在途帧晚于场景切换
- **WHEN** 项目或场景切换已经生效，旧场景仍有渲染结果在后台完成
- **THEN** 视口等待并呈现新场景的画面，旧场景的帧和样本不进入新场景
- **AND** 旧帧使用的资源在相关使用结束后回收

### Requirement: 渲染有效的空白场景
系统 SHALL 支持渲染具备有效相机和背景设置、且网格、实例、材质和灯光均为空的场景。

#### Scenario: 使用两条可用渲染路径显示空场景
- **WHEN** 用户打开空白场景并分别使用设备支持的光栅化和路径追踪
- **THEN** 两种路径都输出对应的背景画面，视口可以继续响应相机和显示操作
