# Spec Delta

## ADDED Requirements

### Requirement: 按场景保存和恢复渲染流程
系统 SHALL 随场景保存最后一次生效的流程与当前草稿，并在打开或切换场景时分别恢复它们。系统 SHALL 根据当前设备能力选择可执行的预览流程，保留场景原有的配置。

#### Scenario: 恢复包含未应用草稿的场景
- **WHEN** 用户保存一个包含生效流程和未应用草稿的场景并重新打开它
- **THEN** 视口使用该场景的生效流程，Render Flow 显示原草稿及其未应用状态
- **AND** 草稿即使尚未通过执行验证，也能作为可继续编辑的内容恢复

#### Scenario: 在两套流程间切换场景
- **WHEN** 用户切换到保存了不同流程的场景
- **THEN** 视口和流程编辑器使用目标场景各自的生效配置和草稿

#### Scenario: 设备不支持场景的光追配置
- **WHEN** 用户打开已保存可用光追流程的场景，但当前设备不满足光追要求
- **THEN** 系统使用可用的光栅化预览，并标明实际模式和原因
- **AND** 保存场景其他改动时，原本的光追配置及草稿仍会保留
