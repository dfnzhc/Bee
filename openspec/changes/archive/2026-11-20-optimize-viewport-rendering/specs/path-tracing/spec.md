# Spec Delta

## ADDED Requirements

### Requirement: 按场景变更范围更新加速结构

路径追踪 SHALL 复用未变化网格的底层加速结构，并按实例或几何的实际变更范围更新可追踪场景。

#### Scenario: 移动使用共享网格的实例

- **WHEN** 一个实例的变换改变，网格本身保持不变
- **THEN** 系统复用该网格的 BLAS，并使用更新后的实例数据更新或重建 TLAS
- **AND** 追踪结果体现移动后的实例，其余共享同一网格的实例仍处于各自的位置

#### Scenario: 仅变更材质或灯光

- **WHEN** 材质或灯光变化，且几何、实例和加速结构的构建条件不变
- **THEN** 路径追踪使用更新后的材质或灯光数据，BLAS 与 TLAS 的构建和更新计数不增加

## MODIFIED Requirements

### Requirement: 状态变化后重置累积

路径追踪模块 SHALL 在影响路径追踪结果的状态变化时丢弃不再有效的累积历史，并在纯显示参数变化时保留有效历史。

#### Scenario: 相机或场景变化

- **WHEN** 相机、几何体、实例变换、材质或光源发生影响路径追踪结果的变化
- **THEN** 后续画面从新的采样历史开始，不混入变化前的样本
- **AND** 仍在执行的旧采样不得贡献到新历史

#### Scenario: 渲染设置或尺寸变化

- **WHEN** 影响路径追踪结果的参数或输出尺寸发生变化
- **THEN** 系统重置受影响的累积历史

#### Scenario: 仅调整曝光

- **WHEN** 只改变色调映射的曝光，且已有有效累积结果
- **THEN** 本次显示更新复用该累积结果及其对应的样本数
