# Tasks

## 1. 应用与 Vulkan 基础

- [x] 1.1 建立 Rust 工作区和 GPUI 应用入口，验证 Windows 上能够编译并打开基本窗口。
- [x] 1.2 初始化自研 Vulkan 后端并报告设备与基础图形能力，验证无可用设备时会显示明确错误。
- [x] 1.3 分别检测光追所需的扩展、feature 和属性；用能力组合测试验证缺少光追时光栅化仍可初始化。
- [x] 1.4 加入开发期 Vulkan 验证层和错误日志，验证可用与不可用两种情况下的报告。
- [x] 1.5 实现当前帧所需的命令提交和资源生命周期管理，验证资源不会在 GPU 使用期间被释放。
- [x] 1.6 建立可复现的着色器到 SPIR-V 构建流程，验证构建成功及着色器错误可诊断。

## 2. 场景画面接入闭环

- [x] 2.1 使用自研 Vulkan 后端生成可识别的离屏测试画面，验证画面内容与资源提交正常。
- [x] 2.2 验证 GPUI 接入点、设备匹配、纹理格式、外部句柄和同步方式，记录本机共享纹理是否可行及原因。
- [x] 2.3 在共享能力可用时接入并验证 GPU 纹理交接；不可用时验证系统能够识别共享能力缺失。
- [x] 2.4 实现 Vulkan 画面异步读回到 GPUI 的回退和接入方式提示，验证颜色、行跨度与画面内容正确；两种路径均失败时显示错误。
- [x] 2.5 处理视口调整尺寸、最小化、恢复及旧资源回收，验证画面恢复且 Vulkan 验证层不报告相关资源错误。

## 3. 共享场景与相机

- [x] 3.1 建立共享几何体、实例、基础漫反射材质、光源及相机数据，并测试内置场景的数据和坐标约定。
- [x] 3.2 实现视口相机输入及相机变换，测试操作后相机状态和变换矩阵相应变化。
- [x] 3.3 建立可区分场景、相机及影响渲染参数变化的版本信息，使用测试验证变更能被渲染器观察到。

## 4. 渲染图基础

- [x] 4.1 实现算法模块图的数据结构、连接类型及必需输入校验，测试有效连接、缺失输入和类型不匹配。
- [x] 4.2 实现依赖循环检查和流程原子生效，测试无效编辑保留并标识上一份有效流程。
- [x] 4.3 实现内部渲染工作及资源读写声明、依赖排序和冲突检查，测试正确顺序、未定义读取与冲突写入。
- [x] 4.4 根据资源用途生成 Vulkan 所需同步与布局转换，使用前后依赖的测试工作验证结果及验证层报告。
- [x] 4.5 区分临时、跨帧历史和外部资源，测试跨帧保留、资源替换和外部资源交接。
- [x] 4.6 实现线性场景颜色、色调映射和视口输出模块，验证基础颜色转换以及输出连接。

## 5. 光栅化路径

- [ ] 5.1 实现场景几何体的 Vulkan 光栅化和深度测试，验证相互遮挡的表面显示正确。
- [ ] 5.2 加入基础漫反射材质和直接光照，验证光源或表面方向变化会影响结果。
- [ ] 5.3 将光栅化模块接入渲染图和共享相机，验证移动相机、调整视口及经色调映射显示的画面。

## 6. 路径追踪

- [ ] 6.1 实现所需几何体加速结构及其构建同步，验证内置场景的加速结构成功构建且验证层不报告相关错误。
- [ ] 6.2 创建 Vulkan 光追流水线、着色器绑定表和基础着色器，验证支持设备能对内置场景求交并输出首个光线追踪画面。
- [ ] 6.3 实现漫反射路径采样及至少两次表面交互，验证简单场景中存在间接光照贡献。
- [ ] 6.4 实现直接光采样、遮挡判断及一致的贡献权重，验证遮挡结果并检查直接与间接贡献不重复计入。
- [ ] 6.5 实现跨帧累积和样本计数，使用固定状态及可控样本验证新样本被正确累积。
- [ ] 6.6 按相机、场景、追踪参数和尺寸变化重置历史，测试连续变化及在途旧帧不会污染新历史；验证仅更改色调映射不重置有效采样。
- [ ] 6.7 将路径追踪模块接入渲染图和视口，验证运动时持续更新、静止后继续累积，并在光追不可用时保留光栅化。

## 7. 可视化流程编辑

- [ ] 7.1 在 GPUI 中显示算法节点、端口与连接，实现节点添加和移除，并验证操作反映在编辑中的流程。
- [ ] 7.2 实现连接、断开及模块参数编辑，验证无效连接或缺失输入会显示原因且不破坏上一份有效流程。
- [ ] 7.3 提供光栅化和路径追踪的可用流程，让用户通过连接切换实际输出，验证节点变化确实改变视口渲染路径。

- [ ] 8.2 在开发验证模式运行上述端到端流程，检查并处理 Vulkan 验证层报告的资源生命周期、同步和布局错误。
- [ ] 8.3 编写启动方式、依赖、能力要求、当前画面接入路径及限制，按说明在 Windows 上完成一次启动验证；不设置帧率验收门槛。
